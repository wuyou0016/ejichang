**先给结论**：机场排行榜可以当作**候选名单**，不能当作**购买结论**。判断一份榜单是否值得参考，看它有没有交代依据。

## 一份合格的榜单应该有什么

| 项目 | 应该写清楚 |
| --- | --- |
| 排序依据 | 按什么排：资料完整度、价格、还是实测 |
| 数据来源 | 官方页面、第三方资料，还是自测 |
| 测试信息 | 如果有测速：时间、地点、方法、样本 |
| 更新时间 | 最近一次更新是什么时候 |
| 局限说明 | 没有测什么、哪些是宣称 |

## 常见问题

- 只有名次，没有依据；
- 名次一年不变；
- 所有条目都是好评，没有任何适用限制；
- 数据来源写“站长实测”，但没有任何记录。

## 怎么把榜单用好

1. 从榜单里挑 2 家资料相对完整的；
2. 各买最低档包月；
3. 晚高峰自己测几天，见 [自测清单](/tools/)；
4. 再决定续费。
