**先给结论**：免费 VPN 的主要问题不是“慢”，而是**你无法核实它怎么处理你的数据**。它适合临时应急，不适合承载敏感账号。

## 常见风险

| 风险 | 说明 |
| --- | --- |
| 限速与限流量 | 免费用户资源受限，稳定性差 |
| 广告与追踪 | 靠广告或数据变现 |
| 隐私政策不透明 | 没有清楚的日志与数据处理说明 |
| 来源不明的安装包 | 可能被篡改 |
| 突然失效 | 缺少长期运营承诺 |

## 怎么判断一个免费 VPN 是否可以临时用

1. 是否来自官方应用商店或官网；
2. 是否有清楚的隐私政策与联系方式；
3. 是否要求与代理无关的权限；
4. 是否有明确的运营主体。

任何一项不满足，就不建议使用。

## 更稳的做法

- 用最低档付费包月替代长期免费，见 [VPN 怎么选](/vpn/)；
- 保留一个应急备用，但不在其上登录重要账号；
- 关键账号只在你信任的服务里使用。
