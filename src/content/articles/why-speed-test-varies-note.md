**先给结论**：测速数字每天不同是正常的，因为它受时段、节点负载、你的本地网络和测速工具共同影响。要让结果有意义，就要**固定条件、多次测量、看趋势**。

## 常见的影响因素

| 因素 | 说明 |
| --- | --- |
| 时段 | 晚高峰运营商网络与节点更拥挤 |
| 节点负载 | 同一节点用户多时变慢 |
| 本地网络 | Wi-Fi 信号、路由器、同时下载的设备 |
| 测速工具 | 不同工具的测试服务器和算法不同 |
| 协议与线路 | 不同协议的开销和表现不同 |

## 怎么让结果更可比

1. 固定测速时间段（例如每天 21:00 前后）；
2. 固定测速工具与目标；
3. 用有线网络或近距离 Wi-Fi 测；
4. 每次多测几次，取中间的值；
5. 记录进 [记录表](/tools/)，看几天的趋势。

## 哪些数字更值得看

- **丢包率**与**抖动**，比瞬时带宽更能反映稳定性；
- **晚高峰的表现**，比深夜的峰值更贴近日常；
- **你常用的网站体验**，比测速分数更真实。

## 不要过度解读

一次测速的高分或低分，都不足以决定要不要续费。连测几天、有记录再决定。更完整的方法见 [稳定梯子怎么判断](/knowledge/stable-ladder-guide/)。
