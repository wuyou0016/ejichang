**先给结论**：这些词经常出现在同一段话里，看起来像同义词，其实并不在同一个层面。**梯子、翻墙、科学上网**多是口语里对“用途”的叫法；**VPN** 是一类具体技术和产品；**机场**是一种服务形态，通常指提供多个节点、以订阅方式使用的代理服务。分清层面，就不容易在选购和搜索时被误导。

## 一张表看清

| 叫法 | 主要指什么 | 所处层面 | 说明 |
| --- | --- | --- | --- |
| 梯子 | 用来访问海外网络的工具或服务的口语叫法 | 用途，口语 | 泛指，没有严格定义，本站也用它作总称 |
| VPN | 虚拟专用网络，一类通过加密通道连接远端网络的技术与产品 | 技术与产品 | 原本用于企业远程接入，后来也被个人用户使用 |
| 机场 | 提供多个节点、通过订阅链接使用的代理服务 | 服务形态 | 由服务方运营节点，用户订阅后在客户端里使用 |
| 科学上网 | 对访问海外网络的一种委婉说法 | 用途，口语 | 与“梯子”指向相近，语气不同 |
| 翻墙 | 描述“绕过网络限制”这一行为的口语说法 | 用途，口语 | 带有行为色彩，语境不同含义略有差异 |
| 节点 | 服务方部署的一个转发服务器或入口 | 组成部分 | 机场通常提供多个节点 |
| 订阅 | 获取节点配置的链接或方式 | 使用方式 | 客户端通过它拉取节点列表 |
| 客户端 | 你设备上运行的软件 | 使用工具 | 用来导入配置并连接 |

## 每个词的进一步解释

### 梯子

它是一个形象的比喻，指“越过障碍的工具”。因为是口语，没有统一的技术含义：它可能指一个 VPN，也可能指一个代理客户端，或者一个机场服务。本站在标题里使用“梯子”，是因为这是很多人的搜索习惯，文中会尽量说明具体指的是哪一类工具。关系细节可以看 [梯子、VPN 与机场的关系](/knowledge/ladder-vpn-airport-relationship/)。

### VPN

VPN 是 Virtual Private Network 的缩写，字面意思是“虚拟专用网络”。它的基本功能是在你和远端网络之间建立一条加密通道。企业里常用它让员工在外面安全地访问公司内网；个人用户则用它来加密流量或改变出口位置。VPN 与代理的技术差别见 [VPN 和代理有什么区别](/knowledge/vpn-vs-proxy/)。

### 机场

“机场”是社区里的叫法，指提供代理节点的服务商。用户购买套餐后，得到一个订阅链接，导入客户端就能看到多个节点。它的核心特征是**多节点、订阅制、按流量或时长计费**。基础概念可看 [机场代理是什么](/knowledge/what-is-airport-proxy/)。

### 科学上网与翻墙

两者都是口语说法，指访问被限制的海外网络这一行为。“科学上网”是较委婉的说法，“翻墙”则更直白。本站的文章主要用中性的技术描述，例如“代理”“梯子”“VPN”，只在需要对应搜索习惯时才会出现这些词。

## 它们是并列还是包含关系

可以这样理解：

1. **用途**：用户想“访问海外网络”，于是有了梯子、翻墙、科学上网这些叫法；
2. **实现方式**：实现这个用途的技术，包括 VPN、各类代理协议；
3. **服务形态**：把这些技术打包成商业服务，包括 VPN 服务、机场；
4. **使用工具**：客户端、订阅、节点，是服务与用户之间的连接。

所以“梯子”不是一个与 VPN、机场并列的产品分类，而是用途层面的总称。

## 选购时怎么避免被名称误导

- **看它实际怎么工作**：是系统级通道，还是应用级代理，是否需要导入订阅；
- **看它给出的信息**：运营主体、客户端、规则、售后；
- **别只按名字搜索**：同一种东西有多个叫法，搜索时可以换词；
- **对夸张说法保持警惕**：什么都能做、永远稳定、完全匿名，这类说法通常不可信；
- **对比时用同一口径**：把 VPN 和机场放在一起比较前，先看 [VPN 与机场怎么选](/knowledge/vpn-or-airport/)。

## 软件层面的分类

不同客户端功能差别也很大，有的只是一个 VPN 应用，有的是支持多种协议的代理工具。可以先看 [梯子软件有哪几类](/knowledge/fanqiang-software-types/) 建立整体印象。

## 还有哪些常见的相关词汇

理解了上面几个核心词，再来看几个经常一起出现的术语，就不那么陌生了。

| 词汇 | 一句话解释 |
| --- | --- |
| 代理 | 替你转发网络请求的中间服务器，是很多梯子和机场的技术基础 |
| 协议 | 客户端与服务器之间约定的通信方式，决定了加密、握手和特性 |
| 线路 | 数据从你到出口所经过的网络路径，会影响速度和稳定 |
| 出口 | 流量最终离开服务方网络、进入目标网站的位置 |
| 中转 | 在入口和出口之间增加的一段转发，常用于优化连接 |
| 倍率 | 部分节点消耗流量时的计算系数，具体规则以服务方说明为准 |
| 分流 | 按规则决定哪些流量走代理、哪些直连 |
| 全局 | 所有流量都走代理的模式 |
| 规则 | 客户端里用来判断分流的一组条件 |
| 延迟与丢包 | 衡量网络质量的两个基础指标 |

这些术语在后面的文章里会陆续出现，遇到不熟悉的词，可以回到这里对照，或者阅读 [协议对比](/knowledge/protocols-compared/)。

## 搜索时怎么用这些词

不同的词在搜索时对应的意图不同，了解这一点，可以更快找到需要的内容：

- **想弄清概念**：用“是什么”“区别”“关系”这类问法，搭配具体名词；
- **想选购**：关注价格、套餐、退款、稳定性，而不是只搜名称；
- **想解决问题**：搜索具体的现象，比如“连不上”“变慢”“掉线”，再加上你使用的客户端名称；
- **想了解安全与风险**：搜索“风险”“隐私”“泄露”，并留意内容的来源与更新时间。

对于任何一篇文章或榜单，都值得问一句：它有没有说明依据，是否标明了信息的来源与时间。这样比仅仅记住几个名词更有用。

## 为什么会出现这么多叫法

原因大致有三点：

1. **口语传播**：这些词首先在社区和论坛里流传，没有统一的定义；
2. **语境不同**：同一件事，在技术讨论、日常聊天和商业宣传里，会用不同的说法；
3. **产品演变**：早期以 VPN 为主，后来出现了更多基于代理协议的服务，名称也跟着变化。

了解这些背景，就能理解为什么同一个东西有很多名字，也就不必被某一个词束缚。

## 常见误区

- **“机场就是 VPN”**：机场多基于代理协议，形态与传统 VPN 不同；
- **“科学上网和翻墙是两种工具”**：只是叫法不同，不是产品分类；
- **“梯子一定要付费”**：免费与付费的差别主要在运营方式与风险；
- **“名字里有 VPN 就代表安全”**：安全取决于服务方，不取决于名称。
