**先给结论**：梯子掉线要**由近到远排查**：先本地网络和设备，再客户端和设置，最后才是节点和服务本身。很多人一掉线就怀疑服务不好，实际上路由器、设备后台策略、订阅到期、系统时间不对，都是常见原因。定位到层级，再决定是调整设置、换节点，还是换服务。

## 先分清是哪一种“掉线”

| 现象 | 可能的方向 |
| --- | --- |
| 整个网络都不通，不开梯子也不通 | 本地网络、路由器、运营商 |
| 不开梯子正常，开了梯子全部不通 | 客户端、节点、订阅状态 |
| 某个节点不通，别的节点正常 | 该节点或线路问题 |
| 定时或固定时段断开 | 节点限速、晚高峰拥挤、设备休眠 |
| 切换网络后断开 | 客户端没有自动重连 |
| 锁屏或后台后断开 | 系统后台策略杀掉了客户端 |

## 排查顺序

### 第一层：本地网络

1. 关掉梯子，访问国内常用网站，确认基础网络正常；
2. 重启路由器和光猫，观察是否改善；
3. 换成手机热点再试，如果热点下稳定，问题多半在家庭网络；
4. 检查路由器是否有限速、防火墙、家长控制之类的设置。

### 第二层：设备与系统

1. **系统时间**：时间不准确，可能导致某些协议握手失败，务必开启自动校时；
2. **后台策略**：手机需要允许客户端自启动、后台运行，并关闭电池优化，见 [手机梯子怎么选](/knowledge/phone-ladder-guide/)；
3. **休眠设置**：笔记本合盖或睡眠后，连接会中断，需要重新连接；
4. **杀毒或防火墙**：暂时关闭，看是否有影响，但不要长期关闭。

### 第三层：客户端与配置

1. 更新客户端到最新版本，旧版本可能与新的协议或订阅格式不兼容；
2. 重新更新订阅，确认节点列表是最新的，方法见 [订阅导入说明](/tutorials/how-to-import-subscription/)；
3. 检查是否同时开了多个代理或 VPN，需要只保留一个；
4. 如果使用 TUN 模式，尝试切回系统代理，看是否稳定；
5. 配置导入报错的话，先看 [Clash 配置导入失败](/troubleshooting/clash-import-failed/)。

### 第四层：节点与订阅

1. 在客户端内切换到同一地区的其他节点，看是否稳定；
2. 换一个不同地区的节点，进一步判断；
3. 登录服务方的用户页面，确认订阅是否到期、流量是否用完、设备数是否超限；
4. 查看服务方的公告或状态说明，看是否有维护或线路调整；
5. 不同节点都出现同样的问题时，再考虑是服务整体问题。

## 用记录来定位规律

掉线的原因往往有规律，你可以简单记录下面几项：

- 掉线的时间（是否集中在晚间）；
- 当时使用的网络（家里 Wi-Fi、手机流量、公司网络）；
- 当时使用的节点和协议；
- 掉线前后你在做什么（看视频、下载、锁屏）；
- 是否需要手动重连才能恢复。

记录几天后，再对照上面的表，通常就能看出是网络、设备还是节点的问题。稳定性判断的更多方法，可见 [稳定梯子怎么判断](/knowledge/stable-ladder-guide/)。

## 什么时候该考虑换服务

满足以下几项时，再考虑更换服务，而不是继续调整：

1. 不同网络、不同设备下都出现同类掉线；
2. 多个节点都不稳定，且集中在同一时段；
3. 客户端和设置已按官方教程配置无误；
4. 服务方长期没有回应或公告。

换服务前，先包月小额试用，并保留原有订阅到过渡期结束，避免中间空档。

## 几种典型的掉线情境与思路

**情境一：每隔固定时间就断一次。** 如果间隔非常规律，比如每过一小时或每天同一时刻，往往和某种“定时”机制有关：设备的省电策略、路由器的定时重拨、服务方对长连接的时间限制，都可能造成这种情况。可以先看路由器是否有定时重启或重新拨号的设置，再看客户端是否有“保持连接”或“自动重连”选项。

**情境二：只在晚间断线。** 这通常和晚高峰的拥堵有关，可能是本地运营商的出口拥堵，也可能是某些节点负载过高。此时先换节点，如果各个节点都在同一时段出问题，再检查本地网络，在下一个晚高峰做对照测试。

**情境三：看视频时断，看网页时不断。** 视频持续占用带宽，更容易暴露链路中的丢包和限速。可以降低画质测试，并查看流量是否触发了限速。

**情境四：多设备同时使用时断线。** 设备数量超过订阅的限制，或者家里带宽被占满，都可能造成这种现象，见 [设备数量说明](/knowledge/airport-multi-device/)。

**情境五：更新客户端或系统后开始掉线。** 新版本可能带来默认设置的变化，需要对照更新说明检查，必要时回退到之前稳定的版本，或者重新导入配置。

## 掉线时先看哪些信息

客户端通常有日志或连接状态页面，掉线时不要急着关掉，可以先看一眼：

- **是否提示超时、握手失败还是认证错误**：超时多指向网络或节点，认证错误多指向订阅或账号状态；
- **节点延迟是否变成无法测试**：如果所有节点都无法测试，问题多在本地；
- **系统里是否有网络断开的提示**：可能是 Wi-Fi 本身断了；
- **流量和有效期信息是否正常**：用尽或过期后，客户端通常会表现为完全连不上。

把这些信息记录下来，即使需要联系服务方，也能提供更有价值的线索。

## 预防掉线的习惯

1. 保存两三个可用的节点，出问题时可以快速切换；
2. 开启客户端的自动更新订阅和自动重连功能（如果有）；
3. 定期检查系统时间、设备电量策略和客户端版本；
4. 关键时刻之前提前连接并测试，不要等到开始才发现连不上；
5. 手机上安装一个备用客户端，电脑遇到问题时可以用手机热点顶一下。

## 常见误区

- **“掉线一定是节点问题”**：本地网络和设备后台策略同样常见；
- **“重装客户端就能解决”**：如果原因在网络或订阅，重装没有意义；
- **“把所有节点都测一遍”**：先按层级排除，比盲目测试更省时间。

连接完全建立不了的情况，可以直接参考 [连接失败排查](/troubleshooting/connection-failed-troubleshooting/)。使用任何工具时，请遵守你所在地区的法律法规。
