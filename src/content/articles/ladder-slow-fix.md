**先给结论**：梯子变慢是一个**链路问题**，你的设备、家里的宽带、运营商、节点、目标网站，任何一段都可能是瓶颈。一次测速没有说服力，要做的是**对比测试**：关掉梯子和开着梯子对比，换节点对比，换时段对比。每一次只变化一个条件，才能定位。

## 数据要怎么流动

数据从你的设备出发，要经过：本地网络（Wi-Fi、路由器、宽带）→ 运营商 → 节点所在网络 → 目标网站，再原路返回。任何一段拥堵，你感受到的都是“慢”。所以排查要分层：

| 层级 | 怎么判断 | 常见原因 |
| --- | --- | --- |
| 本地网络 | 不开梯子，国内网站也慢 | Wi-Fi 信号弱、多设备占带宽、宽带故障 |
| 客户端与设置 | 开了梯子才慢，换客户端或模式有变化 | 模式不合适、规则错误、旧版本 |
| 节点与线路 | 换节点后明显变化 | 节点拥挤、线路绕远、限速 |
| 时段 | 同一节点白天快、晚上慢 | 晚高峰拥堵 |
| 目标站点 | 只有某些网站慢 | 对方服务器或 CDN 问题 |

## 排查顺序

1. **不开梯子，先测本地**：访问国内常用网站，看看下载和网页是否正常，必要时用手机热点做对照；
2. **换个设备对比**：同一 Wi-Fi 下另一台设备是否同样慢；
3. **重启客户端和设备**：长时间运行后连接状态可能异常；
4. **更新订阅和客户端**：节点列表和版本过旧会影响体验；
5. **检查模式与规则**：全局模式下国内流量也绕路，会明显变慢，可改用规则模式；
6. **切换节点**：先换同一地区的其他节点，再换不同地区，观察变化；
7. **换协议或线路**：如果服务提供多种协议，可以对比，协议的特点见 [协议对比](/knowledge/protocols-compared/)；
8. **换时段测试**：分别在上午、下午和晚间做同样的操作；
9. **确认流量与限速**：有些套餐流量用尽后会限速，需要在服务方页面确认。

## 测速时要注意什么

- 同一个测速工具、同一个目标，重复测几次，取大致范围而不是单次数字；
- 只测下载速度不够，网页打开慢通常和延迟、丢包有关，见 [测速怎么看](/knowledge/airport-speed-test-explained/)；
- 不同时间的测速结果差异很大，属于正常现象，原因可见 [为什么每天测速结果都不一样](/knowledge/why-speed-test-varies-note/)；
- 测速站点本身走的线路也不同，不能完全代表你要访问的网站。

## 常见原因与对应处理

| 现象 | 处理方向 |
| --- | --- |
| 所有网站都慢，包括国内 | 先处理本地网络，重启路由器，检查带宽占用 |
| 只有海外网站慢，且各节点都慢 | 检查是否是晚高峰，换时段或换线路 |
| 只有一个节点慢 | 换节点，不要死守 |
| 视频缓冲但网页正常 | 看下载速度和流量是否受限，降低画质测试 |
| 开了 TUN 后变慢 | 尝试切回系统代理，检查 DNS 设置 |
| 刚续费或换套餐后变慢 | 确认订阅更新，重新导入 |

## 节点选择的小建议

- 不必一直选延迟数值最低的节点，节点的延迟只反映连通速度，不代表下载吞吐；
- 保留两三个常用节点，随时切换；
- 对于不同用途，比如看视频和浏览网页，可以选不同的节点，更多可参考 [节点与线路说明](/knowledge/airport-nodes-guide/)。

## 什么时候需要联系服务方

当你已经排除了本地网络，并且多个节点在多个时段都很慢时，可以整理以下信息再联系服务方：

1. 出现问题的时间段；
2. 使用的客户端、版本和节点名称；
3. 同一网络下不开梯子的对照结果；
4. 你已经尝试过的处理步骤。

信息越具体，越容易得到有效回复。也可以先看 [节点变慢排查](/troubleshooting/airport-node-slow/)。

## 一次完整的对比测试怎么做

为了避免凭感觉下结论，可以按下面的方式做一次对比测试，全程大约需要二十分钟，并把结果记录在一张简单的表里。

| 测试项 | 条件 | 你要记录的内容 |
| --- | --- | --- |
| 基线 | 不开梯子，访问国内常用网站 | 页面打开速度、下载速度大致范围 |
| 开梯子 | 使用当前节点，访问同一个海外站点 | 页面打开速度、是否卡顿 |
| 换节点 | 同地区另一个节点 | 与上一项相比的变化 |
| 换地区 | 不同地区的节点 | 与上一项相比的变化 |
| 换设备 | 另一台设备、同一节点 | 是否同样慢 |
| 换时段 | 晚高峰再做一次 | 是否明显变慢 |

每次只改变一个条件，其余保持不变。做完之后，对照表格，就能看出哪个环节的变化最大。示例：如果开梯子后所有节点都同样慢，而换到手机热点后变快，说明问题更可能在家庭网络，而不在节点。

## 节点拥挤与限速的迹象

节点的问题常有这样的表现：

- 延迟看起来正常，但下载速度上不去；
- 同一节点白天正常，晚上下降明显；
- 刚连接时很快，用一会儿之后变慢；
- 大文件下载速度波动很大；
- 换到另一个节点后立刻恢复。

这些迹象说明节点本身的负载或限速策略可能是原因。此时最直接的办法是换节点，而不是反复重连。如果服务方提供了不同线路类型，可以按用途选择，见 [节点与线路说明](/knowledge/airport-nodes-guide/) 中的讲解。

## 如何减少不必要的变慢

1. **使用规则模式**：让国内流量直连，只有需要的流量走代理；
2. **避免叠加多层代理**：同时开着多个工具，会增加转发环节；
3. **视频降低画质**：晚高峰时把画质调低一档，往往比强行等待缓冲更有效；
4. **错峰下载**：需要下载大文件时，选择清晨或深夜；
5. **保持客户端更新**：新版本常包含对协议实现的优化；
6. **合理选择协议**：不同协议的握手和开销不同，如果客户端提供选择，可以做对比测试。

## 常见误区

- **“测速数字低就是服务差”**：需要先看是哪一层的问题；
- **“换最贵的套餐就快”**：套餐只改变额度和权益，不保证线路；
- **“每次变慢都换服务”**：先做分层排查，避免反复付费试错。
