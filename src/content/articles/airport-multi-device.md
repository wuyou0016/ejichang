不少人在选机场套餐时会碰到"设备数"这个参数：一个订阅能不能手机、电脑、平板一起用？家里的路由器算几台？这篇说明设备数限制常见的几种方式，以及下单前该问清楚什么。整体的套餐和流量算法见[机场套餐、流量和倍率怎么算](/knowledge/airport-subscription-guide/)。

## 设备数限制常见的几种方式

不同服务商对"设备数"的定义并不统一，常见有几种做法，**具体以服务商官方说明为准**：

| 限制方式 | 大致含义 | 使用上要注意 |
| --- | --- | --- |
| 同时在线设备数 | 限制同一时间连接的设备数量 | 超出后新连接的设备可能被拒绝或挤掉旧连接 |
| 绑定设备数 | 限制能使用该订阅的不同设备总数 | 换新设备可能需要解绑旧设备 |
| 按 IP 数限制 | 以连接来源的公网 IP 数量计算 | 手机切换网络（Wi-Fi 与流量）时 IP 会变化，可能被计为多个 |
| 不限制设备数 | 官方不设上限 | 仍可能受流量、并发或异常检测规则约束 |

有的服务商这几种会混合使用，因此看到"支持 3 台设备"时，不能直接理解为"随便哪三台都行"。

## 几个容易踩到的情况

- **手机在 Wi-Fi 和移动网络间切换**：如果是按 IP 数限制，同一台手机可能因为 IP 变化被识别为多个设备。
- **路由器算不算一台**：路由器上部署代理后，接在路由器下的所有设备共用同一个出口，服务商可能只算一台，也可能有单独规定，需要先问清楚。
- **多个客户端共用同一订阅**：同一台电脑上同时开两个客户端，或者手机和平板用同一个订阅，都会占用名额。
- **订阅链接被分享给别人**：分享出去的链接同样会占用设备数和流量，还有泄露风险，见[用机场安全吗](/knowledge/airport-privacy-safety/)。
- **设备数与流量是两回事**：设备数多不代表流量够用，多台设备同时使用会更快消耗流量。

## 下单前建议向服务商核对的问题

1. 设备数按"同时在线""绑定设备"还是"IP 数"计算？
2. 超出设备数时，是拒绝新连接、挤掉旧连接，还是需要手动处理？
3. 路由器、电视盒子这类设备怎么计算？
4. 换新设备需要怎么解绑旧设备？有没有次数限制？
5. 你要用的系统（Windows、macOS、iOS、Android、路由器）是否都有可用的客户端？不同平台的配置见[使用教程](/tutorials/)。

如果官网没有写清楚，可以在下单前通过服务商公开的支持渠道询问，并保留回复记录。**回答含糊、只给口头承诺的，值得多留个心眼**。

## 设备数和"够不够用"怎么判断

- 只在一两台设备上用，多数设备数限制都够。
- 家里有多人共用，需要把设备数、流量和倍率一起算，看单价是否真的划算，见[性价比机场怎么选](/rankings/best-value/)。
- 需要在路由器上使用的，优先确认服务商是否明确支持并说明了路由器设备如何计数。
