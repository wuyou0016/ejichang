v2rayN 是 Windows 上另一个常见的机场客户端，和 Clash 系相比，它不依赖规则语法配置，界面更接近"选服务器、点连接"这种直接操作方式，适合不想理解 Clash 规则文件的用户。如果你的机场同时支持 V2Ray/Xray 系协议的订阅格式，通常也能在 v2rayN 里使用。不同版本界面细节可能有出入，具体菜单名称请以你安装的版本实际显示为准。

## 第一步：下载安装

v2rayN 的安装包通常通过其 GitHub Releases 页面分发，选择适合自己系统的版本下载（常见的是免安装的压缩包，解压后直接运行）。部分版本需要系统已安装对应版本的 .NET 运行环境，如果启动时提示缺少运行环境，按提示安装一次即可，之后不需要重复安装。

## 第二步：拿到订阅链接

订阅链接由你购买的机场服务商在其用户后台提供，机场E家不销售套餐，只做导航和信息整理，可以先看[机场导航](/airports/)挑选服务商。不同客户端对订阅链接的通用处理方式基本一致，完整的通用步骤也可以参考[机场订阅链接导入教程](/tutorials/how-to-import-subscription/)。

## 第三步：添加并更新订阅

打开 v2rayN，在"订阅设置"（Subscription Setting）里新建一条订阅，把订阅链接粘贴进对应字段并保存。保存后回到主界面，使用"订阅更新"（Update Subscriptions）功能拉取节点列表，成功后主窗口会显示这个机场当前提供的所有服务器条目。

## 第四步：选择节点

在服务器列表里可以看到每个节点的名称、所在地区等信息，双击某一条或右键选择"设为活动服务器"，即可把它设置为当前使用的节点。挑选节点时可以留意名称里的地区、专线等标签，具体含义可以参考[机场协议对比](/knowledge/protocols-compared/)里对不同协议特点的说明。

## 第五步：开启系统代理或 TUN 模式

只是选中节点还不够，需要在系统代理菜单里选择让流量真正走这个节点：

- **系统代理**：适合大多数日常浏览场景，设置后系统会通过节点访问网络，配置简单；
- **TUN 模式**：会在系统层面接管更多网络流量，覆盖范围更广，但通常需要额外安装网络驱动组件，并以管理员权限运行程序才能生效，如果不确定是否需要，先从系统代理开始。

Windows 上系统代理和 TUN 模式的取舍逻辑，也可以对照[电脑梯子怎么选](/knowledge/computer-ladder-guide/)里关于两者的说明。

## 第六步：验证是否连接成功

打开浏览器访问一个平时打不开的网站，能正常加载即说明代理生效。v2rayN 的主界面通常也会显示当前节点的延迟测试结果，可以点击测试按钮参考一下，但这个数字只反映测试当时的瞬时情况，不代表实际打开网页时的真实体验，也不能作为判断这个机场好不好的唯一依据。

## 换节点时要注意什么

日常使用中，如果发现当前节点变慢或者不稳定，可以直接在服务器列表里双击切换到另一个节点，不需要重新导入订阅。切换节点后建议重新打开一次浏览器标签页再测试，部分网页会缓存之前的连接状态，直接刷新可能还是走的旧节点残留的连接。

## 常见问题

**导入订阅后服务器列表是空的？** 常见原因是订阅链接已过期、套餐到期，或复制时链接不完整，建议回服务商后台重新复制一次完整链接，再执行一次订阅更新。

**该用系统代理还是 TUN 模式？** 日常浏览用系统代理基本够用；如果发现某些应用（游戏、部分下载工具）没有走代理，再考虑切换到 TUN 模式。

**v2rayN 和 Clash 该选哪个？** 两者都能正常使用机场订阅，主要区别在配置方式：Clash 系依赖规则文件、灵活度更高；v2rayN 操作更直接。选服务商支持的订阅格式对应的客户端即可，两个都装、按需切换也可以。

**订阅更新失败怎么办？** 先检查电脑本身能否正常访问网络（关闭代理测试一次），排除本地网络问题；再确认订阅链接是否还在有效期内；如果两者都正常，可能是订阅链接本身临时无法访问，稍后重试或联系服务商确认。

## 同时管理多个机场的订阅

如果你同时订阅了不止一个机场，v2rayN 支持添加多条订阅记录，更新时可以选择只更新其中一条，也可以一次性更新全部。不同机场的节点会分别显示在服务器列表里，通常会带上各自的分组或订阅名称前缀，方便区分。日常使用时只需要确认当前选中、生效的是哪一条服务器，避免误连到已经到期或暂时不打算用的那个机场的节点。

## 关于路由规则的简单说明

部分版本的 v2rayN 也提供简单的路由规则设置，比如"绕过局域网和大陆地址"这类预设选项，作用和 Clash 里的规则模式类似——让访问国内网站的流量直连、不经过节点，减少不必要的绕行。如果你不清楚具体规则含义，保持默认设置通常就够用；确实需要精细控制分流规则时，建议先熟悉一种客户端把基础流程走通，再考虑要不要换成规则语法更灵活的 Clash 系客户端。

## 安全性提示

订阅链接和 Clash 里的情况一样，属于你的账号凭证，不要分享给他人，也不要粘贴到来源不明的"订阅转换"网站，具体注意事项见[共享账号和订阅链接有什么风险](/knowledge/ladder-account-sharing-risk/)。软件本身建议只从官方发布渠道下载，避免使用来路不明的修改版本。

如果连上之后依然打不开网页，或者出现具体报错，可以按[机场连不上、网页打不开怎么排查](/troubleshooting/connection-failed-troubleshooting/)里的顺序继续排查。
